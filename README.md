# WypozyczalniaAut
## Car rental shop app with 2 roles of users and XML integration
.NET version 8.0

## Description
Car rental app with a small UI made with WPF. There are 2 types of users and a data base of cars which uses XML. The users are: admins and clients. There is no current implementation for admin users, as UI only includes client-side information. User can register itself as one and have a look on the list of available cars.

UI is in Polish
